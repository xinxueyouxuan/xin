# 迷宫逃脱（控制台版）

C 语言写的回合制迷宫游戏，单文件 `1.c`。

你在左上角，出口在右下角，路上有鬼巡逻。中间横着一条河，得把箱子推下去搭成桥才能过去。

## 符号

| 符号 | 含义 | 符号 | 含义 |
|---|---|---|---|
| `人` | 你 | `鬼` | 鬼 |
| `墙` | 墙 | `河` | 河流，走不过去 |
| `箱` | 箱子，可以推进河里 | `桥` | 箱子沉下去后形成的桥 |
| `心` | 回血道具（+3） | `定` | 定身符，鬼停 8 回合 |
| `门` | 出口 | `．` | 按 R 时标出的路线 |

## 操作

| 按键 | 作用 |
|---|---|
| `W` `A` `S` `D` 或方向键 | 移动一步（按一下就走，不用回车） |
| `R` | 枚举到出口的所有路线，并在图上标出最短那条 |
| `Q` | 退出 |

## 玩法规则

**血条**：满血 10 点，顶上一行实时显示 `生命[##########] 10/10`。

**被鬼抓到**：扣 2 点血，随后进入 **4 回合无敌**，期间不再受伤（HUD 会显示倒计时）。血扣到 0 就 GAME OVER。

**鬼**：每回合与你同时行动。离你 5 格以内会沿最短通路追过来，否则随机巡逻且不走回头路。默认 2 只（`GHOST_COUNT` 可调）。

**河与桥**：河是必经之路上的障碍，直接撞上去会被挡住。解法是把旁边的箱子朝河的方向推下去——箱子落水后变成桥，之后就能走过去了。

推箱子有两条规则，都是为了避免卡死：
- 只能推到河里（推去别处会被拒绝）
- 箱子必须正对着河才能推，绕到它背后那格再按方向键

**道具**：踩上去自动生效。心回 3 点血；定身符让所有鬼停 8 回合，期间它们不会移动，是逃命或绕后的好机会。道具只会刷在你走得到的地方。

撞墙不消耗回合，鬼也不会动。

## 怎么运行

| 方式 | 操作 |
|---|---|
| 调试运行 | 按 **F5**，弹出独立控制台窗口 |
| 在 VS Code 终端里玩 | **Ctrl+Shift+B** 编译 → `终端 → 运行任务 → 构建并运行` |
| 直接跑 | 双击 `1.exe` |

> 要先把 **`raylib游戏` 这个文件夹本身**用 VS Code 打开，`.vscode` 里的配置才会生效。

## 命令行参数

```
1.exe [迷宫边长N=12] [额外打通的墙数=0]
```

- `N`：迷宫边长（格），范围 6–16，默认 12
- `额外打通的墙数`：0–20。默认生成的是**树**（任意两点唯一通路）；打通若干面墙后会有多条路线，这时按 `R` 的排序才有意义

例：`1.exe 14 5` —— 14×14 的迷宫，额外打通 5 面墙。

终端的行数要够：`N=12` 时迷宫占 25 行，加上标题和提示共 27 行。窗口太矮会滚动，画面会乱。

## 代码结构

```
1.c
├─ 数据结构
│   ├─ Edge      邻接表结点（格子之间的通路）
│   ├─ Stack     顺序栈，DFS 回溯用
│   └─ Route     一条候选路线（长度 + 格子序列）
├─ 图
│   ├─ link_cells / has_edge   建边、查边（有边 = 中间没有墙）
│   ├─ bfs                     求各格到玩家的通路距离（鬼追击用）
│   └─ bfs_path                BFS 记前驱，找出起点到出口的必经之路
├─ 生成
│   ├─ gen_maze          DFS 回溯生成迷宫（生成树 ⇒ 唯一通路）
│   ├─ pick_river_spot   在必经之路上挑一段直道，放河和箱子
│   ├─ build_river_and_box
│   └─ place_items       在玩家可达处撒道具
├─ 路线
│   ├─ dfs_routes        DFS 回溯枚举 s→t 的全部简单路径
│   └─ find_routes       枚举后按长度 qsort 升序
├─ ghost_move     追击 / 巡逻
├─ draw_hud       血条 + 无敌/定身倒计时
├─ draw           把图渲染成字符网格
└─ main           主循环：清屏 → 绘制 → 读一个键 → 更新
```

几个实现要点：

- **迷宫用图存**，不是二维墙数组。`adj[i]` 是格子 `i` 的邻接表，两个格子之间有边就表示互通，渲染时再翻译成 `墙` 和空地。
- **DFS 回溯用在两处**：生成迷宫时"能走就走、走不通就弹栈"，枚举路线时"进栈标记、递归、出栈取消标记"。
- **河必须放在直道上**。玩家要站在箱子背后才能推，如果路在那儿拐弯，"背后"那格可能是墙，站不上去就成死局了。`pick_river_spot` 要求连续四格共线，输出的地图已用脚本验证过 105 张全部可解。
- **中文排版**：每个符号都是两列宽的汉字（空地用全角空格），所以网格天然对齐；启动时用 `SetConsoleOutputCP(CP_UTF8)` 让控制台按 UTF-8 解释输出。
- **输入用 `_getch()`**，读一个键立刻返回；方向键会先发 `0` 或 `224` 前缀再跟键码，代码里做了翻译。
- **清屏用控制台 API**（`FillConsoleOutputCharacterA` + `SetConsoleCursorPosition`），比 `system("cls")` 快且不闪。

## 编译

```bash
gcc -std=c99 -Wall -Wextra 1.c -o 1.exe
```

菜单里 `Ctrl+Shift+B` 用的是项目配好的任务（额外带 raylib 链接参数，对这个控制台程序没有影响）。

## 注意

- `conio.h` 和 `windows.h` 都是 **Windows 专有**的。拿到 Linux 或在线评测平台编译会报错，那边得换 `termios` 或 `fgets`。
- 想调难度：`GHOST_COUNT`（鬼的数量）、`HP_MAX`（血量）、`DMG`（每次伤害）、`INV_TURNS`（无敌回合）、`FREEZE_TURNS`（定身回合），都在文件开头。
