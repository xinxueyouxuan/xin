JavaScript 循环与控制语句全演示

请查看每个模块下方的 蓝色结果框 查看运行效果。

1. while 循环 (先判断，后执行)

代码逻辑：var i = 1; while(i <= 5) { ... i++; }

2. do...while 循环 (先执行一次，再判断)

代码逻辑：即使初始条件不成立，也会强制执行一次。

3. for 循环 (最常用)

代码逻辑：基础 1-10 遍历 & 数组遍历。

4. break 语句 (彻底终止循环)

代码逻辑：在 0-9 的循环中，遇到 i == 5 立刻停止。

5. continue 语句 (跳过本次，继续下一次)

代码逻辑：在 0-9 的循环中，跳过所有偶数（i % 2 == 0）。
